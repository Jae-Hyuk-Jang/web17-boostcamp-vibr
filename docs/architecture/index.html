stateDiagram-v2
  [*] --> Loading: 앱 로드 (isLoading=true)
  Loading --> Guest: 세션 토큰 없음
  Loading --> Authenticated: /user/me 조회 성공 (setAuth)

  Guest --> Authenticated: 로그인 성공 (setAuth)
  Authenticated --> Guest: 로그아웃 (clearAuth)

  Authenticated --> SessionExpired: /user/me 401 + 토큰 일치 확인\n(client.ts, 다른 API의 401은 무시)
  SessionExpired --> Guest: clearAuthState()\n(store 초기화 + LoginModal 오픈)
