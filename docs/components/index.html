VIBR 컴포넌트 쇼케이스

apps/web/src/components/에서 실제로 파악한 공용/재사용 컴포넌트를 설명과 함께 실제 모양(색상·간격·상태)까지 재현해 정리한 문서입니다. Tailwind 클래스 대신 apps/web/app/globals.css의 실제 디자인 토큰 값으로 CSS를 다시 작성해 외부 의존성 없이 이 파일 하나로 렌더링됩니다 — 실제 컴포넌트와 100% 동일한 렌더러는 아니고, 구조·색·상태 전이를 눈으로 확인하기 위한 참고용 재현입니다.
